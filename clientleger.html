Projet Client Léger - Natation Develop

Présentation du projet

Le projet "Natation Develop" est une application web permettant de gérer les compétitions et les performances des nageurs. Son but est de fournir une solution complète aux clubs de natation pour :

  • 📌 Enregistrer et suivre les performances des nageurs
  • 📌 Gérer les compétitions
  • 📌 Administrer les utilisateurs (entraîneurs, nageurs, administrateurs)
  • 📌 Offrir une API REST pour faciliter l’intégration avec d’autres systèmes

Structure du projet

natation-develop/
│--  app/                # Code métier (Modèles, Contrôleurs)
│--  routes/             # Définition des routes web et API
│--  resources/views/    # Fichiers Blade (Interface utilisateur)
│--  database/           # Migrations et modèles de la base de données
│--  public/             # Assets publics (CSS, JS, images)
│--  tests/              # Tests unitaires et fonctionnels
│--  documents/          # Documentation et suivi du projet
│--  .env.example        # Variables d’environnement
│--  composer.json       # Dépendances PHP (Laravel, PHPUnit)
│--  package.json        # Dépendances JS (Tailwind, Chart.js)

Productions réalisées

Fonctionnalité Description
Authentification & rôles Gestion des comptes avec rôles : Admin, Entraîneur, Nageur
Gestion des nageurs Ajout, modification, suppression et consultation des nageurs
Gestion des compétitions Planification et suivi des compétitions
Suivi des performances Stockage et affichage des résultats des nageurs
API REST avec Swagger API pour accéder aux données au format JSON
Visualisation des performances Graphiques des temps et progressions des nageurs
Sécurité & Permissions Middleware pour restreindre l'accès selon le rôle
Documentation technique Guide d’installation, d’utilisation et API
